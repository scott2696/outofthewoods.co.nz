## 5. On-page integration rules (how we avoid stuffing)

1. **Primary keyword appears in:** title tag (front-loaded), H1, first 100 words,
   one H2, meta description, one image alt, the canonical URL slug, and the
   schema `name`/`headline`. That is eight placements and it is enough.
2. **Never repeat the exact primary more than ~6 times** in a 2,500-word page.
   Target density under 0.6%. Use variants and pronouns instead.
3. **Every H2 targets a distinct sub-intent**, phrased as a user would say it.
   H2s are questions or noun phrases, never keyword strings.
4. **FAQ questions use near-verbatim PAA phrasing** — the question is the
   keyword, so the body can be written naturally.
5. **Tables carry keyword-adjacent entity terms** (payment names, studio names,
   licence names) at high density without reading as prose stuffing. This is the
   most efficient place to build entity coverage.
6. **Long-tail is answered in a dedicated paragraph or FAQ**, not sprinkled.
7. **Bold is used for the answer, not the keyword.** Bolding keywords is a
   1990s signal and now reads as spam to both readers and raters.
